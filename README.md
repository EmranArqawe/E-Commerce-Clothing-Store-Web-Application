# 🛍️ E-Commerce Clothing Store

An interactive front-end web application built for an online fashion store experience. The project focuses on clean UI design and efficient client-side logic to handle product cataloging, promotional offers, and real-time financial calculations.

---

## 🚀 Key Features

* **Intelligent Time-Based Greeting**: Personalized user interface feedback based on the local system time.
* **Dynamic Pricing Engine**: Automated calculations for product totals, including integrated tax handling (3%).
* **Promotional Logic Implementation**: Logic-driven discount system supporting custom promotional offers and "Buy 2, Get 1 Free" bundle validation.
* **Responsive UI/UX**: Designed with focus-state feedback and CSS grid layouts to ensure a smooth interaction flow.

---

## 🛠️ Built With

* **Frontend**: HTML5
* **Styling**: CSS3 (Grid Layouts, Interactive State Design)
* **Scripting**: JavaScript (DOM Manipulation, Date Handling, Business Logic Algorithms)

---

## 📦 How to Run the Project

1. Clone or download this repository.
2. Ensure all project files and images are in the same directory.
3. Open `1.html` in any modern web browser to view the application.
